# modern-rust-guidance

An [Agent Skill](https://agentskills.io) that helps AI coding agents write **current** Rust instead of the older Rust they learned from.

> [!NOTE]
> This project was generated by AI. Claude (Anthropic) wrote the guides, the `mrg` CLI, this README and every commit, with Daniel directing the work. The guides were checked against official Rust sources and their code snippets compile, but they can still contain mistakes. Please open an issue if you find one.

## Why

Models learn from years of old Rust. So they still write `lazy_static!`, deep `match` blocks instead of `let … else`, `map_or(false, …)`, hand-rolled `div_ceil`, and extra `.clone()` calls. This skill gives the agent short, verified guides on how to do it today, and the agent only uses features your project's Rust version supports.

## What's inside

- **29 guides**: 26 topic guides plus 3 overview guides (one per category).

  | Category | Examples |
  | --- | --- |
  | `std` | `let … else`, `LazyLock`, `Option`/`Result` combinators, integer math, errors, edition 2024, lint setup |
  | `performance` | measuring first, allocations, needless copies, buffered I/O, release profile, lock contention |
  | `testing` | clear assertions, test isolation, testable design, doc tests, Miri |

  Each guide states the minimum Rust version it needs and the clippy lints that catch the old pattern. Every code snippet in the guides compiles.
- **`mrg`** (optional): a small command-line tool for searching and reading the guides. It has no dependencies and makes no network calls. You can skip it, because the agent can read the guides directly.

The full list is in [`skills/modern-rust-guidance/index.md`](skills/modern-rust-guidance/index.md).

## Install

The skill is the folder `skills/modern-rust-guidance/`. Put it in your agent's skills directory.

```sh
git clone https://github.com/dnlzrgz/modern-rust-guidance ~/src/modern-rust-guidance

# Example: Claude Code, all projects
mkdir -p ~/.claude/skills
ln -s ~/src/modern-rust-guidance/skills/modern-rust-guidance ~/.claude/skills/
```

A symlink stays current when you run `git pull`. If your agent doesn't follow symlinks, use `cp -r` instead. Restart the agent afterwards.

| Agent | All projects | One project |
| --- | --- | --- |
| Claude Code | `~/.claude/skills/` | `.claude/skills/` |
| Codex CLI, Gemini CLI, OpenCode, Cursor, GitHub Copilot | `~/.agents/skills/` | `.agents/skills/` |
| pi | `~/.pi/agent/skills/` | `.pi/skills/` |

Many agents read `~/.agents/skills/`, so one symlink there covers them all. If your agent uses a different path, check its docs. This is a plain Agent Skill folder.

### Optional: install `mrg`

```sh
cargo install --path skills/modern-rust-guidance/cli   # needs Rust 1.85 or newer
```

The agent never installs `mrg` on its own. Without it, search is a bit less precise and `mrg scan` (whole-crate audit) is not available.

## Use

Ask your agent for Rust work as usual, for example "review this crate for outdated code", "make this faster" or "add tests". The skill turns on by itself. The agent then:

1. Finds your project's minimum Rust version (MSRV).
2. Finds and reads the guides that match the task.
3. Applies them, then runs the checks each guide lists (clippy, tests).
4. Ends its reply with a **Modern Rust Guidance** section that names the guides it used.

For a full audit, ask the agent to run `mrg scan`. Note that this builds your project.

## Limits

- **Standard library only.** It doesn't cover async/tokio, third-party crates, API design or unsafe code review.
- On projects that are already modern and well tuned, it mostly confirms that no change is needed. It's most useful on older code and for tests.

## Develop

```sh
cargo test                                  # test the CLI
cargo clippy --all-targets -- -D warnings
cargo run -q -- check --compile --clippy    # validate all guides (compiles their snippets)
cargo run -q -- index > skills/modern-rust-guidance/index.md   # rebuild the guide list
```

`check --compile` runs `rustc` on code from the guides. Only run it on guides you trust.
